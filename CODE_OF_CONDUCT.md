# Code Of Conduct

This project follows a simple professional conduct standard.

Participants should:

- communicate respectfully and directly
- assume good intent while staying precise about technical or scientific concerns
- keep discussions focused on reproducibility, clarity, and correctness
- avoid sharing private patient data, credentials, or unpublished draft material in public channels

Unacceptable behavior includes harassment, personal attacks, publishing private data, or pressuring contributors to disclose data they are not authorized to share.

Report conduct concerns to the repository maintainer.
